# 천년가족 (Sennen Kazoku / 千年家族) - 한국어 번역 프로젝트.

Game Boy Advance용 시뮬레이션 게임 **천년가족(千年家族)**의 비공식 한국어 번역 패치입니다.

Codex를 활용하여 번역 및 프로그램쪽 작업을 하였습니다.
이미지, 텍스트 검수 등은 사람이 합니다.

현재도 끊임없이 수정 중입니다.

## 프로젝트

⚠️ **한국어 패치 베타 배포 (v260829)**
 
![image](https://github.com/user-attachments/assets/d81d32c4-de6b-4119-8144-49d74cc54a19)

변경된 사항은 아래와 같습니다.

- 텍스트와 이미지의 한국어 지원.
- 이름 입력에 한국어 이름 입력기 지원.(단모음 형태입니다.)


## 이슈 제보 및 피드백

텍스트 줄 넘김, 텍스트 깨짐, 번역 어색함(혹은 이상함), 심각한 그래픽 깨짐, 게임 멈춤 등의 문제는 아래 방법으로 제보해 주세요.

- **GitHub Issue**: 새 이슈를 등록해 주세요.
  
- **제보 시 포함할 내용**:
  - 문제가 발생했던 당시의 텍스트, 혹은 스크린 샷.
  - 문제 현상 (예: 글 잘림, 진행 안됨 등.)
  - 사용 중인 에뮬레이터 및 버전.
  - (가능하다면) 스크린샷이나 세이브 파일.(되도록 mgba의 ~.ssx(0~9)의 강제세이브데이터. 다만 멈추거나 이슈가 있기 전의 데이터일수록 좋습니다.)

## 라이선스

- 본 패치 파일은 개인적, 비상업적 용도로 제공됩니다. 원작 게임의 저작권은 해당 권리자에게 있습니다.
- 본 한글패치 파일 자체를 제작자에 허가없이 타 사이트에 재배포하지 말아 주시고, 재배포를 원하실 경우 패치원본 게시물의 링크를 공유해 주시기 바랍니다.
- 본 한글패치 파일을 이용하여 금전적 이득을 취하는 모든 행위를 일절 금합니다. 해당 행위로 발생하는 모든 책임은 이용 당사자에게 있으며, 패치 제작자는 어떠한 책임도 지지 않습니다.
