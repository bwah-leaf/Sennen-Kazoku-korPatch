## 🛠️ 패치 적용 방법 (How to Patch)

1. **원본 ROM 준비**: 일본판 순정 ROM (`Sennen Kazoku (Japan).gba`)
2. **패치 도구 사용**: 온라인 패처([Romhacking.net Web Patcher](https://www.romhacking.net/patch/) 또는 [Marc Robledo Patcher](https://www.marcrobledo.com/RomPatcher.js/)) 접속
3. **적용**: 원본 ROM과 제공된 `.ips` / `.bps` / `.xdelta` 패치 파일을 업로드 후 변환된 ROM 다운로드
4. GBA 에뮬레이터 또는 실기에서 실행

> **주의사항 (Disclaimer)**  
> 저작권법을 준수하며, 본 저장소에서는 원본 ROM 파일을 일절 제공하지 않습니다.  
> 패치 파일 적용을 위해서는 반드시 정품 패키지에서 직접 덤프한 일본판 원본 ROM이 필요합니다.
